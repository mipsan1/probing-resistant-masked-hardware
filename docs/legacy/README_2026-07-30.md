## 7. Failed Attempts (Decision-Grade Negatives)

These are documented as decision-grade evidence that PROLEAD's byte-exact
simulation-stage functional assertion and wire-by-name parser design are
working as documented:

- **PC-G** (variant B): `synth/prolead/synth_for_prolead_d2_nomask.ys`
  synthesized correctly, but **PROLEAD aborts with `Target module
  reg[7:0] not found!`**.  The flatten-disabled Yosys netlist exposes
  sub-module registers that PROLEAD's library mapper cannot resolve.
- **PC-A**: `expected_output = [$$$, 0x42, 0x42]` → share 1, 2 are 0
  but expected is 0x42 → byte-exact mismatch abort.
- **PC-B**: `expected_output = [0x42, 0x42, 0x42]` → share 0 (random
  uniform) cannot be 0x42 → mismatch.
- **PC-D**: `expected_output = [0x42, 0, 0]` → masked design's share 0
  is random, not always 0x42 → mismatch.

**Decision**: All of these confirm that PROLEAD's **byte-exact
simulation-stage functional assertion** is alive.  PC-A/B/D all show
`simulation-stage abort` signatures → channel-alive control.

- **PC-H** (order=2 unmasked): `rtl/circuit_d2_unmasked.v` is standalone
  RTL with AES S-box LUT (256 entries) + y0, y1, y2 wire concat.
  Yosys synthesized correctly, but **PROLEAD aborts with
  `Signal "16'h0000" not found!`**.

**Decision**: This is PROLEAD v3's **documented parser design limitation**.
The unmasked d=2 variant requires the same wire-concat form as the normal
d=2 masked netlist for PROLEAD compatibility.

→ **PC-H RTL/.ys itself is syntax-valid** (18/18 ad-hoc verification
PASS in source); the limitation is only in PROLEAD's library mapping
not recognizing inline literals as modules.

  64,000 sims/probe set.  We honestly report this as **17,157 unique
  sets**, not 33 × 17,157 = 566,181 (which would imply 566,181 distinct
  probe sets, which is wrong).  Each batch is a deterministic
  re-execution of the same design + config.

  PROLEAD due to a library mapping limitation.  **The RTL itself is

  wire-by-name parser cannot resolve the inline literal driver.

  reproducibility requirement.  Reviewer can pull Docker image +
