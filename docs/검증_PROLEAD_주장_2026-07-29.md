### D-2. EXPERT_DIAGNOSIS의 핵심 모순 — 1차 자료로 확인

**d=1 512k=OK vs 1,536k=LEAK는 1차 자료로 그대로 확인됨**:
- 512k: 0/14,400 leak, worst `-log10(p)=3.39` (불확실)
- 1,536k: 160/2,816 leak, **worst `-log10(p)=inf` (수치적으로 결정적 누설)**
- 두 결과는 **probing set의 크기도 다름** (14,400 vs 2,816) → 단순 비교 불가이나, 1,536k의 160 leak이 2,816 set 중 모두 `-log10(p)=inf`라는 것은 **결정적(deterministic) 누설**로 보임 (false positive 노이즈 아님).

**보고서(`논문과 시험의 미진한사항분석.md`)는 이 모순을 단 한 줄도 언급하지 않음**. 보고서 본문에서 "d=1 14,400개"만 인용하고 1,536k 결과는 완전히 침묵.

### D-3. 64k verdict 진동 — 1차 자료로 확인

phaseC_b0 per-step status (8k→64k):
```
8k=OKAY (4.84)  16k=OKAY (4.17)  24k=OKAY (4.16)
32k=LEAKAGE (5.26)  40k=LEAKAGE (5.10)  48k=LEAKAGE (5.70)
56k=LEAKAGE (5.48)  64k=OKAY (4.81)  ← 최종
```
- 32k~56k 구간에서 **5번 연속 LEAKAGE** → 64k에서 OKAY로 수렴
- worst probe는 32k/40k/48k에서 동일 wire(`_001629_(3), _002572_(3)`)에 머무름 → **일관된 wire가 4 step 연속 worst** = 결정적 누설 신호

wsl2_b0 per-step status:
```
8k=LEAK  16k=OKAY  24k=OKAY  32k=OKAY  40k=OKAY
48k=LEAK  56k=OKAY  64k=LEAK
```
- 8k/48k/64k에서 LEAK, 그 사이 OKAY
- worst probe는 16 leak 모두 다른 wire → **false positive 우세 패턴** (실제 누설보다 노이즈에 가까움)

### D-4. 검정력 분석 (EXPERT_DIAGNOSIS의 Layer A)

| 시뮬 수 | worst -log10(p) 분산 | 검출 한계 (Cohen's d) | 17M set에서 1개 leak 검출 확률 (r=1e-5) |
|---|---|---|---|
| 64k | ±2.0 (per-step 진동 관측) | ~0.04 | <50% |
| 512k | ±0.7 (추정) | ~0.014 | ~90% |
| 1,536k | ±0.4 (추정) | ~0.008 | ~99% |

**EXPERT_DIAGNOSIS F2 비판의 타당성**:
- phaseC_b0의 32k~56k LEAK는 **same wire 일관 worst** → 결정적 신호, 노이즈 아님
- 그러나 보고서는 "32k=LEAK, 64k=OKAY는 노이즈 플리커"로 일축
- **이 판단은 절반만 맞음**: wsl2_b0처럼 worst wire가 매번 다르면 노이즈, phaseC_b0처럼 worst wire가 같으면 진짜 누설
- 보고서는 **worst wire의 일관성 vs 비일관성을 구분하지 않고 일괄 "노이즈"로 처리** → 과도한 단순화

### D-5. Bonferroni / Family-wise correction

PROLEAD가 인용한 "univariate evaluation with 17,147,424 probing sets":
- Bonferroni `-log10(α/N) = -log10(0.05/17,147,424) = 8.54` (보고서 미언급)
- 보고서는 "1.99M probing set × α=0.05 → 9.12"를 20% sample에 적용했으나, **전체 17M에 대한 family-wise correction은 미언급**
- EXPERT_DIAGNOSIS는 "17M × 1e-5 → Bonferroni p < 5.9e-12" 주장 — 이건 α=1e-5 기준, `-log10(5.9e-12) = 11.23`
- 두 수치 모두 보고서가 무시 → **family-wise correction 부재는 보고서의 결함**
